## Project 1 – Retail Credit Process Digitalization (Business Analysis)

**Type:** Business Analysis Case Study  
**Tools:** Microsoft Word / Google Docs  

### Overview
As-is/to-be analysis of a personal loan process for a fictional 
retail bank (MDO Bank).

### What I did
- Mapped the full credit lifecycle: origination, decisioning, 
  servicing, monitoring and recovery
- Identified 5 key operational inefficiencies in the current process
- Designed a digitalized to-be workflow including:
  - Automated scoring engine replacing manual Excel-based evaluation
  - Digital onboarding portal for customers
  - Real-time alert system for payment delays (7/30/60 days)
  - End-to-end digital workflow with full traceability
- Defined business rules and functional requirements (REQ-01 to REQ-05)
  for the credit platform implementation

## Project 2 – Credit Portfolio Monitoring Dashboard (Power BI)

**Type:** Interactive Dashboard  
**Tools:** Power BI, Excel, DAX  

### Overview
Interactive 2-page Power BI dashboard for monitoring a synthetic 
personal loan portfolio (100 loans, ~2.1M€ total exposure).

### Page 1 – Credit Portfolio Overview
- KPIs: Total Loans, Total Exposure, High Risk Exposure, 
  Default Rate, Delinquency Rate
- Status distribution (Current, Late_30, Late_60, Defaulted)
- Loan exposure trend over time
- Default rate by Employment Type
- Interactive slicer by Branch and Status

### Page 2 – Risk & Delinquency Analysis
- KPIs: Avg Days Past Due, PAR 30+, PAR 60+, High Risk Loan %
- Default Rate by Branch
- Loans by DPD Bucket (Current, 1–30, 31–60, 61–90, 90+)
- Exposure and Loan Count by Risk Band
- Critical Loans Detail table (filterable by Branch and Risk Band)

### DAX Measures
- Default Rate, Delinquency Rate, PAR 30+/60+
- High Risk Exposure, % High Risk
- Avg Days Past Due, DPD Bucket segmentation
